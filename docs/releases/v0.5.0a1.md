# CyberSLM v0.5.0a1

This is the first usable local alpha of CyberSLM. It is intended primarily for Apple Silicon Macs
with at least 16 GB of unified memory and keeps chat, retrieval, uploads, and model inference on
the local machine.

## Included

- Local Gemma 3 4B text and image chat through MLX
- Six cybersecurity modes and explicit authorization context
- Persistent, renameable, and deletable conversations
- Selective Auto/On/Off RAG over pinned MITRE ATT&CK, CWE, and CAPEC releases
- Local hybrid lexical and semantic retrieval with source-disclosure diagnostics
- Buffered deterministic response guards for the demonstrated alpha blockers
- Optional non-executing C17 syntax checks for generated C blocks
- macOS/Linux shell and Windows PowerShell setup and startup scripts
- SQLite/upload backup tooling and reproducible evaluation commands

## Start on Apple Silicon

```bash
git checkout v0.5.0a1
./setup.sh
uv run cyberslm-knowledge sync
uv run cyberslm-knowledge verify
./start.sh
```

Open <http://localhost:8501>. The Gemma checkpoint downloads lazily from Hugging Face on the first
prompt and is governed by Google's Gemma terms. Model weights and generated knowledge indexes are
not bundled with this GitHub release.

## Alpha limitations

- The full 4B model path has been accepted on Apple Silicon. Linux and Windows launchers and the
  portable Transformers path pass CI, but full-weight runtime quality and performance validation
  on representative Linux and Windows hardware remain post-alpha work.
- Retrieved-reference footers disclose what was consulted; they do not prove that every generated
  factual claim is supported. Inline citation behavior remains inconsistent with this small model.
- Response guards are narrow mitigations for reproduced failures, not a general proof of factual
  correctness or safety. Review security guidance and generated code before operational use.
- CyberSLM does not independently verify authorization claims or execute generated code.
